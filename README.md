## To Report Issues

Include steps to reproduce, expected and actual behavior, your RuneLite and plugin versions, and relevant screenshots or error messages you are getting. Be sure to also note if you are using any features marked "beta" or "experimental". 

In the rare event a plugin causes RuneLite to crash or freeze while loading, including during log-in, please make sure you have turned off conflicting plugins. A list of known conflicting plugins is located on each plugin's main page, and they will be automatically turned off when loading any of mine.
